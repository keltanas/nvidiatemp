# nvidiatemp

Утилита, управляющая скоростью вентилятора NVIDIA GPU: берёт охлаждение под своё управление, когда карта занята, и возвращает его драйверу в простое.

## Language

**Ручной режим**:
Состояние GPU, в котором утилита сама задаёт скорость вентилятора (GPUFanControlState=1). Вход — мощность выше порога мощности; выход — мощность ниже порога И температура ниже нижней границы кривой.
_Avoid_: управляемый режим, manual mode

**Авто-режим**:
Состояние GPU, в котором охлаждение вентилятором ведёт драйвер (GPUFanControlState=0). Безопасное состояние: гарантированно восстанавливается при остановке утилиты.
_Avoid_: автоматический режим, auto

**Порог мощности**:
Значение потребляемой мощности, определяющее вход в ручной режим; по умолчанию 50W.
_Avoid_: лимит мощности, порог нагрузки

**Кривая**:
Зависимость скорости вентилятора (%) от температуры GPU, кусочно-линейная по точкам «температура → скорость»; применяется только в ручном режиме. Ниже первой точки — скорость первой точки, выше последней — скорость последней.
_Avoid_: график, профиль охлаждения

**Нижняя граница кривой**:
Температура первой точки кривой; одновременно температурное условие выхода из ручного режима.
_Avoid_: порог температуры (не путать с порогом мощности)

**Мёртвая зона**:
Минимальное отклонение целевой скорости от текущей, при котором происходит запись; по умолчанию 5%.
_Avoid_: гистерезис, допуск

**Пауза между записями**:
Минимальный интервал между двумя записями скорости вентилятора; по умолчанию 5с.
_Avoid_: троттлинг

**Перехват запуска вентилятора**:
Переход из авто-режима в ручной, когда драйвер сам поднимает скорость вентилятора
не ниже порога перехвата (по умолчанию 30%), а карта при этом не нагружена и не
горяча; длительность удержания — до 3 минут, затем возврат в авто-режим.
_Avoid_: тихий режим, quiet mode (поле конфигурации `quiet_hold` — это длительность перехвата, а не отдельный режим)
