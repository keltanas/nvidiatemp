## Why

RTX 4080 на целевой машине постоянно под нагрузкой (llama-server поверх X-сессии), и штатная авто-кривая драйвера не устраивает. В ручном режиме карта не даёт выставить скорость ниже 30%, поэтому «вручную» охлаждение держать нельзя — нужен демон, который сам берёт управление вентилятором при нагрузке по своей температурной кривой и возвращает его драйверу в простое (там вентилятор может опуститься тише).

## What Changes

- Новый Go-бинарник `nvidiatemp` с подкомандами: `run` (демон), `status`, `set <pct>`, `curve`.
- Цикл управления на каждый видимый GPU: опрос температуры и мощности раз в 2с; мощность > 50W → ручной режим и скорость по линейной кривой температуры (по умолчанию `50→30, 60→40, 65→45, 70→55, 75→60, 80→70`, кламп [30, 100] — аппаратный минимум карты 30%); мощность < 50W **и** температура ниже нижней границы кривой → возврат в авто-режим.
- Защита от дребезга: запись скорости только при отклонении цели от текущей ≥ 5% и не чаще раза в 5с.
- Безопасность: при любой остановке демона (SIGINT/SIGTERM, паника, 5 неудавшихся опросов подряд) гарантированно восстанавливается авто-режим; systemd `Restart=on-failure`.
- Несколько GPU: все видимые карты управляются общей кривой, в конфиге можно задать отдельную кривую на индекс.
- Конфигурация: YAML-файл `/etc/nvidiatemp.yaml` (флаг `-c`), встроенные значения по умолчанию = дефолтная кривая выше; валидация точек кривой при старте.
- Развёртывание: systemd-юнит от root с `DISPLAY=:0`; чтение температуры/мощности — без привилегий, запись скорости — через `nvidia-settings` (sudo добавляется автоматически, если euid ≠ 0).

## Capabilities

### New Capabilities

- `fan-control`: цикл управления вентилятором — опрос, переключение авто/ручной режим по мощности, вычисление целевой скорости по кривой температуры, защита от дребезга, восстановление авто-режима при остановке и при потере связи с драйвером.
- `operator-cli`: интерфейс оператора — подкоманды `run`, `status`, `set <pct>`, `curve` и их наблюдаемое поведение.
- `configuration`: конфигурация — формат YAML-файла, путь по умолчанию, флаг `-c`, значения по умолчанию, валидация при старте, переопределение кривой на индекс GPU.

### Modified Capabilities

(нет — новый репозиторий, существующих спецификаций нет)

## Impact

- Новый Go-модуль, один бинарник; единственная внешняя зависимость — `gopkg.in/yaml.v3`.
- Требования к хосту: драйвер NVIDIA с `nvidia-smi` и `nvidia-settings`, X-дисплей `:0` (для записи), root для сервиса либо sudo для интерактивного использования.
- Существующий код не затрагивается (greenfield).
