## Purpose

Определяет, как настраивается nvidiatemp: YAML-файл конфигурации, его расположение, значения по умолчанию, валидация при старте и переопределение кривой на индекс GPU.

## ADDED Requirements

### Requirement: Файл конфигурации
Система SHALL читать конфигурацию из `/etc/nvidiatemp.yaml` по умолчанию; путь может быть задан флагом `-c <path>`. При отсутствии файла система SHALL работать со встроенными значениями по умолчанию, включая дефолтную кривую.

#### Scenario: Файл отсутствует
- **WHEN** файла конфигурации в пути по умолчанию нет и флаг `-c` не задан
- **THEN** система работает со встроенными значениями по умолчанию

#### Scenario: Пользовательский путь
- **WHEN** задан флаг `-c /tmp/cfg.yaml`
- **THEN** конфигурация читается из `/tmp/cfg.yaml`

### Requirement: Параметры конфигурации
Конфигурация SHALL поддерживать параметры: интервал опроса (по умолчанию 2с), мёртвую зону (по умолчанию 5%), паузу между записями (по умолчанию 5с), порог мощности (по умолчанию 50W), ожидание перед возвратом в авто-режим `auto_delay` (по умолчанию 5 минут), общую кривую — список точек «температура → скорость» — и необязательные переопределения на индекс GPU, каждое со своей кривой.

#### Scenario: Частичная конфигурация
- **WHEN** файл задаёт только кривую
- **THEN** остальные параметры принимают значения по умолчанию

#### Scenario: Переопределение на индекс
- **WHEN** в файле задана кривая для индекса 1, а общая кривая тоже задана
- **THEN** GPU с индексом 1 управляется своей кривой, остальные — общей

### Requirement: Валидация конфигурации
Система SHALL валидировать конфигурацию при старте: температуры точек кривой строго возрастают, скорости лежат в диапазоне [30, 100] (аппаратный минимум карты — 30%), порог мощности положителен. При ошибке валидации система SHALL завершиться с ненулевым кодом и сообщением о проблеме.

#### Scenario: Скорость ниже аппаратного минимума
- **WHEN** точка кривой имеет скорость 20%
- **THEN** запуск завершается ошибкой с указанием проблемы

#### Scenario: Непорядоченные точки
- **WHEN** температуры точек кривой не строго возрастают
- **THEN** запуск завершается ошибкой с указанием проблемы

### Requirement: Дефолтная кривая
Встроенная дефолтная кривая SHALL равняться: 50→30, 60→40, 65→45, 70→55, 75→60, 80→70.

#### Scenario: Кривая не задана
- **WHEN** конфигурация не задаёт кривую (и файла нет)
- **THEN** эффективная кривая равна дефолтной кривой из этого требования
