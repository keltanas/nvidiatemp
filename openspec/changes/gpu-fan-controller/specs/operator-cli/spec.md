## Purpose

Командный интерфейс оператора: запуск демона, разовый просмотр состояния GPU, ручной override скорости вентилятора и вывод эффективной кривой с параметрами.

## ADDED Requirements

### Requirement: Подкоманда run
Система SHALL предоставлять подкоманду `run`, запускающую цикл управления как долгоживущий процесс (демон) до получения сигнала остановки.

#### Scenario: Запуск демона
- **WHEN** выполнена команда `nvidiatemp run` с корректной конфигурацией
- **THEN** система начинает опрос и управление всеми видимыми GPU и работает до SIGINT/SIGTERM или ошибки

### Requirement: Подкоманда status
Система SHALL предоставлять подкоманду `status`, которая разово печатает для каждого видимого GPU: текущую температуру, текущую скорость вентилятора, режим управления (авто/ручной), целевую скорость по кривой и потребляемую мощность.

#### Scenario: Просмотр состояния
- **WHEN** выполнена команда `nvidiatemp status`
- **THEN** для каждого GPU печатается его температура, текущая скорость вентилятора (%), режим, целевая скорость по кривой (%) и мощность (W)

### Requirement: Подкоманда set
Система SHALL предоставлять подкоманду `set <pct>`, которая разово переводит все видимые GPU в ручной режим и выставляет скорость вентилятора равную `<pct>`; цикл управления при этом не запускается. Значение вне диапазона [30, 100] SHALL отклоняться с ошибкой без изменения состояния GPU (аппаратный минимум карты — 30%). Ключевое слово `auto` (`nvidiatemp set auto`) SHALL разово переводить все видимые GPU в авто-режим.

#### Scenario: Ручной override
- **WHEN** выполнена команда `nvidiatemp set 50`
- **THEN** все видимые GPU переведены в ручной режим со скоростью вентилятора 50%

#### Scenario: Возврат в авто
- **WHEN** выполнена команда `nvidiatemp set auto`
- **THEN** все видимые GPU переведены в авто-режим (управление драйвером)

#### Scenario: Недопустимое значение
- **WHEN** выполнена команда `nvidiatemp set 20`
- **THEN** система печатает ошибку, завершается с ненулевым кодом и не изменяет состояние GPU

### Requirement: Подкоманда curve
Система SHALL предоставлять подкоманду `curve`, которая печатает эффективную кривую (общую и переопределения на индексы) и параметры цикла (интервал опроса, мёртвая зона, пауза между записями, порог мощности) с учётом конфигурации и значений по умолчанию.

#### Scenario: Вывод эффективной кривой
- **WHEN** выполнена команда `nvidiatemp curve`
- **THEN** печатаются точки эффективной кривой для каждого GPU и параметры цикла управления

### Requirement: Поведение при отсутствии GPU
Все подкоманды, обращающиеся к GPU, SHALL завершаться с ненулевым кодом и сообщением об ошибке, если видимых NVIDIA GPU нет.

#### Scenario: GPU не обнаружен
- **WHEN** выполнена любая подкоманда, а видимых GPU нет
- **THEN** система печатает ошибку на stderr и завершается с ненулевым кодом
