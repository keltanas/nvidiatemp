- [x] 6.2 Реализовать `status`: разовый вывод per-GPU температуры, текущей скорости, режима, целевой скорости по кривой, мощности; проверить: вывод совпадает с реальным состоянием по `nvidia-smi` / `nvidia-settings -q`
