# nvidiatemp

**Тихие вентиляторы под нагрузкой. Управление драйверу — в простое.**

nvidiatemp — небольшой демон для Linux, который берёт управление вентиляторами NVIDIA GPU на себя, пока карта занята, и возвращает его драйверу, когда карта отдыхает. Вместо резких раскруток драйвера скорость следует заданной кривой температуры, поэтому карта остаётся холодной, но не гудит как турбина.

## Зачем nvidiatemp

- **Тихо под нагрузкой.** Скорость вентилятора меняется плавно, по кривой температуры, — без внезапных раскруток до 100%.
- **Без графического сервера.** Бэкенд NVML по умолчанию работает с драйвером напрямую: ни X-дисплея, ни sudo-обёртки.
- **Безопасно по умолчанию.** Любая остановка демона — сигнал, паника или пять неудачных опросов подряд — возвращает все управляемые GPU драйверу.
- **Поддержка нескольких GPU.** Каждый вентилятор каждой видимой карты адресуется явно, а кривую можно задать отдельно для каждого GPU.
- **Без дребезга.** Мёртвая зона и пауза между записями не дают вентилятору «гулять» вокруг одной температуры.

## Как это работает

- Раз в `poll_interval` (по умолчанию 2 с) утилита читает температуру, потребляемую мощность и текущую скорость вентилятора всех видимых GPU одним вызовом `nvidia-smi`.
- **Ручной режим.** Когда мощность превышает порог (по умолчанию 50 Вт), GPU переводится на ручное управление, и скорость следует кривой (кусочно-линейная интерполяция, ограничение [30, 100]).
- **Возврат в авто-режим.** Карта возвращается драйверу, только когда мощность ниже порога **и** температура ниже нижней границы кривой. После этого вентилятор удерживается на минимальной скорости (30%) в течение `auto_delay` (по умолчанию 5 минут). Если за это время снова появляется нагрузка — мощность выше порога или температура выше нижней границы, — ожидание отменяется, и управление вновь идёт по кривой.
- **Тихий перехват.** Карта без нагрузки (мощность ниже порога) переводится в ручной режим на `quiet_hold` (по умолчанию 3 минуты), а затем возвращается драйверу по одному из двух условий:
  - драйвер сам раскручивает вентилятор (скорость ≥ `quiet_threshold`, по умолчанию 30%), пока карта не нагрета (температура ниже нижней границы кривой);
  - температура держится не ниже `quiet_temp` (по умолчанию 50 °C) непрерывно `quiet_delay` (по умолчанию 1 минуту) — медленный нагрев в простое, когда вентилятор ещё может работать на низких оборотах.

  Во время удержания скорость идёт по кривой (30% у нижней границы). Появившаяся нагрузка завершает удержание досрочно; перехват, начатый по вентилятору, завершается досрочно и при нагреве выше нижней границы. `quiet_hold: 0` отключает оба условия.
- **Без дребезга.** Скорость записывается, только если она отличается от текущей не меньше чем на мёртвую зону (по умолчанию 5%), и не чаще одного раза в `write_pause` (по умолчанию 5 с). Переключения режима подчиняются той же паузе.
- **Бэкенды.** По умолчанию управление идёт через NVML (`backend: auto`): без X-дисплея и без sudo-обёртки, каждый вентилятор карты адресуется явно. `nvidia-settings` остаётся запасным вариантом и включается принудительно через `backend: nvidia-settings`.
- **Безопасность.** При любой остановке демона (SIGINT/SIGTERM, паника, пять неудачных опросов подряд) все управляемые GPU возвращаются в авто-режим.

## Требования

- Linux с драйвером NVIDIA. Чтение идёт через `nvidia-smi` и не требует root.
- Для записи скорости нужен root; юнит systemd из поставки запускает демон от root.
- Бэкенд NVML по умолчанию (`libnvidia-ml`) работает с драйвером напрямую: X-дисплей и sudo-обёртка не нужны.
- Для `backend: nvidia-settings` дополнительно нужны X-дисплей (`DISPLAY=:0`) и root — либо passwordless sudo, если демон запущен от обычного пользователя (sudo подставляется автоматически при euid ≠ 0).

## Сборка

```sh
go build -o nvidiatemp .
```

Один бинарник. Нужны Go 1.27+ и cgo: NVML-бэкенд использует `github.com/NVIDIA/go-nvml`, который загружает `libnvidia-ml` из драйвера во время работы, поэтому для кросс-компиляции нужен C-тулчейн под целевую платформу. Вторая зависимость — `gopkg.in/yaml.v3`.

Готовые бинарники для `linux/amd64` и `linux/arm64` прилагаются к каждому релизу с тегом `v*`: скачайте архив и пропустите этот раздел.

## Установка (systemd)

```sh
sudo install -m 0755 nvidiatemp /usr/local/bin/nvidiatemp
sudo cp deploy/nvidiatemp.example.yaml /etc/nvidiatemp.yaml   # при желании отредактируйте
sudo cp deploy/nvidiatemp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now nvidiatemp
systemctl status nvidiatemp
```

Замечание про `XAUTHORITY` относится только к `backend: nvidia-settings`: если в журнале (`journalctl -u nvidiatemp`) появляются ошибки доступа к X, раскомментируйте в юните `Environment=XAUTHORITY=/home/<user>/.Xauthority` (или выполните `xhost +local:`). Бэкенду NVML по умолчанию дисплей не нужен.

## Подкоманды

| Команда | Что делает |
| --- | --- |
| `nvidiatemp run` | Демон: цикл управления до SIGINT/SIGTERM |
| `nvidiatemp status` | Разовый отчёт по каждому GPU: температура, скорость вентилятора, режим, целевая скорость по кривой, мощность |
| `nvidiatemp set PCT` | Все GPU в ручной режим на PCT процентов ([30, 100]); цикл не запускается |
| `nvidiatemp set auto` | Все GPU обратно в авто-режим (управление драйвером) |
| `nvidiatemp curve` | Действующая кривая (общая и для отдельных GPU) и параметры цикла |

Флаг `-c <path>` задаёт файл конфигурации (по умолчанию `/etc/nvidiatemp.yaml`) для `run`, `status`, `set` и `curve`. У `run` есть также флаг `-v` — подробный лог каждого тика (уровень Debug).

## Конфигурация

Формат и значения по умолчанию описаны в комментариях к [`deploy/nvidiatemp.example.yaml`](deploy/nvidiatemp.example.yaml). Если файла нет, работают встроенные значения: кривая `50→30, 60→40, 65→45, 70→55, 75→60, 80→70`, интервал 2 с, мёртвая зона 5%, пауза 5 с, порог мощности 50 Вт, ожидание перед возвратом в авто-режим 5 минут, тихий перехват на 30% на 3 минуты (в том числе когда карта в простое держится на 50 °C дольше минуты), бэкенд `auto`.

Конфигурация проверяется при старте: температуры точек кривой должны строго возрастать, скорости — лежать в [30, 100], порог мощности — быть больше нуля; при включённом тихом удержании порог перехвата должен входить в (0, 100], `quiet_temp` — быть больше нуля, а `quiet_delay` — неотрицательным; бэкенд должен быть известен. При ошибке процесс завершается с кодом 1 до запуска цикла.

## Ручной возврат в авто-режим

Если демон был остановлен аварийно (`kill -9`, сбой питания), карта может остаться в ручном режиме. Верните её драйверу вручную:

```sh
nvidiatemp set auto
# или без nvidiatemp, для каждого GPU (индекс — как в nvidia-smi):
sudo DISPLAY=:0 nvidia-settings -a "[gpu:0]/GPUFanControlState=0"
```

`nvidiatemp set auto` работает через NVML и не требует X-дисплея; команде `nvidia-settings` выше он нужен.

Проверить текущий режим:

```sh
DISPLAY=:0 nvidia-settings -q GPUFanControlState
nvidiatemp status                             # работает без X (бэкенд NVML)
```

## Откат

```sh
sudo systemctl disable --now nvidiatemp   # при остановке демон сам возвращает авто-режим
sudo rm /etc/systemd/system/nvidiatemp.service /usr/local/bin/nvidiatemp
sudo systemctl daemon-reload
```
