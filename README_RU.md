# nvidiatemp

Утилита для управления скоростью вентилятора NVIDIA GPU: берёт охлаждение под
своё управление, когда карта занята (мощность выше порога), и возвращает его
драйверу в простое — там вентилятор может опуститься тише 30% (аппаратный
минимум ручного режима).

## Как это работает

- Раз в `poll_interval` (по умолчанию 2с) читает температуру, мощность и
  текущую скорость вентилятора всех видимых GPU одним вызовом `nvidia-smi`.
- Мощность выше порога (по умолчанию 50W) → GPU переводится в ручной режим,
  скорость выставляется по кривой «температура → скорость» (кусочно-линейная
  интерполяция, кламп [30, 100]).
- Возврат в авто-режим — только когда мощность ниже порога **и** температура
  ниже нижней границы кривой. После этого вентилятор удерживается на
  минимуме (30%) `auto_delay` (по умолчанию 5 минут) и переход в авто
  происходит, если за это время нагрузка не появилась: любое нарушение условий
  (мощность снова выше порога или температура выше нижней границы) отменяет
  ожидание, и управление снова идёт по кривой.
- Если в авто-режиме драйвер сам раскручивает турбину (скорость ≥
  `quiet_threshold`, по умолчанию 30%) в то время, когда мощность ниже
  порога и температура ниже нижней границы кривой — карта перехватывается
  в ручной режим (скорость по кривой, то есть 30% в простое) на
  `quiet_hold` (по умолчанию 3 минуты), после чего возвращается в
  авто-режим. Если за это время появилась нагрузка или карта нагрелась
  выше нижней границы кривой, удержание заканчивается досрочно и всё
  идёт по криовой. `quiet_hold: 0` отключает перехват.
- Защита от дребезга: скорость записывается только при отклонении от текущей
  ≥ мёртвой зоны (по умолчанию 5%) и не чаще раза в `write_pause`
  (по умолчанию 5с); паузе подчиняются и переключения режима.
- Управление вентилятором идёт через NVML (по умолчанию `backend: auto`): без
  X-дисплея и без sudo, каждый вентилятор карты адресуется явно.
  `nvidia-settings` остаётся запасным вариантом (`backend: nvidia-settings`).
- Безопасность: при любой остановке демона (SIGINT/SIGTERM, паника,
  5 неудавшихся опросов подряд) все управляемые GPU возвращаются в авто-режим.

## Требования

- Linux с драйвером NVIDIA; чтение идёт через `nvidia-smi` (без root).
- Запись по умолчанию идёт через NVML (`libnvidia-ml`): X-дисплей и sudo не
  нужны. С `backend: nvidia-settings` нужны X (`DISPLAY=:0`) и root либо
  passwordless sudo для интерактивного использования (sudo подставляется
  автоматически, если euid ≠ 0).

## Сборка

```sh
go build -o nvidiatemp .
```

Один бинарник. Сборка требует cgo: NVML-бэкенд использует
`github.com/NVIDIA/go-nvml`, который загружает `libnvidia-ml` из драйвера во
время работы, поэтому для кросс-компиляции нужен C-тулчейн под целевую
платформу. Вторая зависимость — `gopkg.in/yaml.v3`.

## Установка (systemd)

```sh
sudo install -m 0755 nvidiatemp /usr/local/bin/nvidiatemp
sudo cp deploy/nvidiatemp.example.yaml /etc/nvidiatemp.yaml   # при желании — отредактировать
sudo cp deploy/nvidiatemp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now nvidiatemp
systemctl status nvidiatemp
```

Относится только к `backend: nvidia-settings`: если в журнале
(`journalctl -u nvidiatemp`) появляются ошибки доступа к X, раскомментируйте в
юните `Environment=XAUTHORITY=/home/<user>/.Xauthority` (или используйте
`xhost +local:`). Бэкенду NVML по умолчанию дисплей не нужен.

## Подкоманды

```
nvidiatemp run    демон: цикл управления до SIGINT/SIGTERM
nvidiatemp status разовый вывод per-GPU: температура, скорость, режим, целевая скорость по кривой, мощность
nvidiatemp set PCT все GPU в ручной режим со скоростью PCT ([30, 100]); цикл не запускается
nvidiatemp set auto все GPU обратно в авто-режим (управление драйвером)
nvidiatemp curve  эффективная кривая (общая + per-index) и параметры цикла
```

Флаг `-c <path>` задаёт файл конфигурации (по умолчанию `/etc/nvidiatemp.yaml`)
для `run`, `status`, `set` и `curve`. У `run` есть `-v` — логирование каждого
тика (Debug-уровень).

## Конфигурация

Формат и значения по умолчанию описаны в комментариях
[`deploy/nvidiatemp.example.yaml`](deploy/nvidiatemp.example.yaml). При
отсутствии файла работают встроенные дефолты: кривая `50→30, 60→40, 65→45,
70→55, 75→60, 80→70`, интервал 2с, мёртвая зона 5%, пауза 5с, порог 50W,
ожидание перед возвратом в авто 5 минут, перехват запуска вентилятора на
30% на 3 минуты, бэкенд `auto`.
Конфиг валидируется при старте (температуры точек строго возрастают, скорости
в [30, 100], порог мощности > 0, бэкенд известен) — при ошибке процесс
завершается с кодом 1 до начала цикла.

## Ручной возврат в авто-режим

Если демон остановлен не штатно (`kill -9`, сбой питания), карта может
остаться в ручном режиме. Вернуть драйверу вручную:

```sh
nvidiatemp set auto
# либо без nvidiatemp, для каждого GPU (индекс — как в nvidia-smi):
sudo DISPLAY=:0 nvidia-settings -a "[gpu:0]/GPUFanControlState=0"
```

`nvidiatemp set auto` работает через NVML и X-дисплей ему не нужен; строка с
`nvidia-settings` выше — нужен.

Проверить текущий режим:

```sh
DISPLAY=:0 nvidia-settings -q GPUFanControlState
nvidiatemp status                             # работает без X (бэкенд NVML)
```

## Откат

```sh
sudo systemctl disable --now nvidiatemp   # при остановке демон сам возвращает авто-режим
sudo rm /etc/systemd/system/nvidiatemp.service /usr/local/bin/nvidiatemp
sudo systemctl daemon-reload
```
